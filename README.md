# SimpleConsoleCalc

A console calculator project for beginners of C++.

- Beginner friendly
- Easy to apply newly acquired knowledge on
- Suitable as a template to build upon

## Main idea
It parses prompts of user by looping through each character extracting numbers and operators and then solves the problem following order of evaluation (precedence).

## How to get
Clone/Download code and build the solution file [SimpleConsoleCalc.sln](SimpleConsoleCalc.sln) using Visual Studio. And that's it !
